# رِواق — متجر ومنصة خدمات

واجهة عربية RTL متجاوبة بتصميم راقٍ وصور منتجات أصلية لمتجر يجمع المنتجات والخدمات، مع سلة وطلب بالدفع عند الاستلام ولوحة إدارة محمية.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث. من مجلد المشروع شغّل:

```bash
npm start
```

ثم افتح `http://localhost:3000`. كلمة مرور الإدارة المحلية الافتراضية هي `change-me-now`؛ غيّرها قبل أي نشر.

## النشر على Render

1. ارفع الملفات إلى مستودع GitHub.
2. في Render اختر **New → Blueprint** واربط المستودع الذي يحتوي على `render.yaml`.
3. أدخل قيمة قوية وفريدة لـ `ADMIN_PASSWORD` عندما يطلبها Render، ثم أنشئ الخدمة.
4. افتح رابط الموقع واضغط **إدارة المتجر** للدخول إلى لوحة التحكم.

الإعداد يرفق قرصًا دائمًا بمسار `/var/data` حتى تبقى المنتجات والطلبات محفوظة بعد إعادة تشغيل الخدمة أو نشر نسخة جديدة. أبقِ قرص البيانات مرتبطًا بالخدمة ولا تحذف محتوياته. لا تستخدم كلمة المرور الافتراضية على الإنترنت.

## ماذا تتضمن النسخة؟

- متجر عربي متجاوب، بحث وتصنيفات وفصل بين المنتجات والخدمات.
- سلة مشتريات وطلب بالدفع عند الاستلام، مع بيانات العميل والعنوان.
- نموذج إرسال طلب خدمة ومتابعته.
- لوحة إدارة بكلمة مرور: مؤشرات المبيعات والطلبات، ملخص مرئي لآخر سبعة أيام وحالات الطلب، ومتابعة الطلبات وتحديثها، وإضافة المنتجات والخدمات وتعديلها وحذفها.
- أصول بصرية أصلية للواجهة وبطاقات المنتجات، مع ملفات قليلة بدل بنية مجزأة كثيرة.
- حفظ البيانات في ملف JSON داخل قرص Render الدائم، دون خدمة قاعدة بيانات خارجية أو حزم تشغيل إضافية.

العملة المعروضة حاليًا هي الريال السعودي، ووسيلة الدفع هي الدفع عند الاستلام؛ الربط مع بوابة دفع أو الشحن يحتاج تفعيل حسابات ومفاتيح مزود الخدمة.
